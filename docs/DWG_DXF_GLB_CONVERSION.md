# DWG to GLB Conversion: Technical Background

## The Problem

DWG is Autodesk's proprietary binary format. These particular DWG files store
3D geometry as **3DSOLID** entities, which internally use the **ACIS format**
(Spatial Corp / Dassault Systemes). ACIS is a proprietary B-rep (boundary
representation) kernel -- no open-source library can decode it.

## What Is ACIS?

ACIS (Alan, Charles, Ian's System) is a geometric modeling kernel. Inside a
DWG/DXF file, 3DSOLID entities contain ACIS binary data (SAB format) that
describes solid geometry using mathematical surface definitions (planes, cones,
splines, etc.) rather than triangle meshes.

To display this geometry in a web viewer (GLB/glTF), the ACIS B-rep data must
be **tessellated** -- converted from mathematical surfaces into triangle meshes.
This requires the ACIS kernel itself, which is commercially licensed.

## Why DXF Does Not Help

Converting DWG to DXF (via ODA File Converter) preserves the file structure in
an open text format, but the ACIS binary data inside 3DSOLID entities is copied
as-is. The DXF format does not tessellate the geometry. So while tools like
ezdxf can read DXF files, they still cannot extract mesh data from 3DSOLID
entities.

## The Solution: APS API

Autodesk Platform Services (APS, formerly Forge) is Autodesk's cloud API. The
**Model Derivative API** translates DWG files server-side using Autodesk's
proprietary geometry engine, which includes the ACIS kernel.

Pipeline:
```
DWG --> Upload to APS --> Model Derivative (DWG to SVF) --> Download SVF --> GLB
```

Key details:
- Uses 2-legged OAuth v2 for authentication
- DWG is uploaded to Object Storage Service (OSS) via signed S3 upload
- Translation produces SVF format (Autodesk's viewer format)
- `forge-convert-utils` (Node.js) reads SVF and outputs glTF
- `gltf-pipeline` packages glTF into single GLB file

## SVF vs SVF2

- **SVF**: Older viewer format. Supported by `forge-convert-utils`. This is what we use.
- **SVF2**: Newer format. NOT supported by `forge-convert-utils` (no reader exists). Avoid.

## Alternative Approaches

If APS is not suitable (e.g., commercial licensing concerns), the customer can
export DWG as **STL** or **OBJ** from AutoCAD/BricsCAD before sending the file.
These mesh formats bypass ACIS entirely since the CAD software tessellates the
geometry during export.

## Commercial Considerations

- APS free tier is available for development and testing
- Commercial use requires a paid APS subscription
- SVF files cannot be generated by customers (only produced by APS cloud API)
- Customers cannot "split the pipeline" by sending SVF -- it is not an export format
